> 在这里先把素材**收集归档**，后续在电脑端逐条进行**爆款拆解**。

## 📂 目录结构

```
.
├── README.md            # 本文件：总索引 + 使用说明

└── 拆解/                 # 每条视频一个 MD 文件，存放在这里
    └── (示例) 001-视频标题.md
```

## 🚀 使用流程

1. **收集**：刷到爆款视频，先在上方「素材清单」里登记一行（链接、博主、题材、日期）。
2. **建档**：复制 `拆解模板.md`，重命名为 `拆解/编号-标题.md`。
3. **拆解**：在电脑端按模板逐项拆解（钩子、脚本结构、文案、剪辑节奏、爆款逻辑等）。
4. **归档**：拆解完更新清单状态为 ✅，沉淀可复用的套路。

## 🎯 拆解关注的核心维度

- **钩子（前 3 秒）**：怎么在开头留住人
- **脚本结构**：起承转合 / 信息节奏
- **文案与标题**：标题、字幕、标签（#）
- **视听呈现**：画面、转场、BGM、节奏
- **爆款逻辑**：戳中了什么情绪 / 需求 / 痛点
- **可复用点**：我能怎么套用到自己的内容
